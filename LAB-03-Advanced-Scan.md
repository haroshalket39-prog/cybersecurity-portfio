# LAB-03: Детекция Xmas Scan и логика анализа IP Spoofing
**Статус:** Выполнено
**Роль:** Аналитик Blue Team (SOC)
**Окружение:** Ubuntu Linux (Live-USB Ventoy в RAM) + tcpdump + Wireshark

## 1. Сводка инцидента (Summary)
В ходе контролируемого ИБ-тестирования локального периметра проведена симуляция продвинутых техник сетевой разведки и скрытности: сканирования типа Xmas Scan и подмены сетевых идентификаторов (IP Spoofing). Цель работы — фиксация аномальных заголовков пакетов и разбор логики их детекции.

## 2. Часть 1: Анализ Xmas Scan («Рождественское сканирование»)
Для перехвата трафика использовалась связка `tmux` и `tcpdump`. Эмуляция атаки проводилась с помощью утилиты Nmap (флаг `-sX`) по портам 80, 443 и 3389.

### Ход анализа:
Для изоляции хакерских пакетов применен специализированный дисплейный фильтр:
`tcp.flags == 0x029`

* **Результат детекции:** Фильтр успешно перехватил пакеты, в которых на транспортном уровне (L4 TCP) были одновременно взведены три бита: `FIN` (1), `PSH` (8) и `URG` (32). Сумма битовых флагов составила `41` (в шестнадцатеричном формате — `0x029`), что подтверждает структуру Xmas-пакета.
* **Реакция системы:** Так как целевые порты на сервере находились в закрытом статусе, операционная система хладнокровно отработала стандарт RFC 793, отправив в ответ пакеты с флагом `RST` (Reset) для жесткого сброса соединений.

## 3. Часть 2: Логика вычисления IP Spoofing (Подмена адресов)
При маскировке атакующего методом генерации ложных IP-адресов на Сетевом уровне (L3) стандартные логи фаерволов нижнего порядка становятся неэффективными.

### Метод детекции аналитиком SOC:
Для раскрытия истинного источника угрозы проводится сквозной анализ на Канальном уровне (L2) в заголовке Ethernet II:
1. Фиксируется значение поля `Source MAC` (уникальный физический адрес сетевой карты/роутера отправителя).
2. При сопоставлении пакетов вычисляется аномалия: если атака идет от множества различных IP-адресов, но все они имеют идентичный `Source MAC`, хост однозначно признается скомпрометированным методом IP Spoofing. Железный адрес устройства деанонимизирует атакёра.

## 4. Вердикт
1. Сигнатура атаки Xmas Scan успешно изучена и зафиксирована по шестнадцатеричному маркеру `0x029`.
2. Логика сквозного анализа L2/L3 уровней для борьбы с IP Spoofing полностью освоена.
