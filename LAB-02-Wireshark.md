# LAB-02: Анализ Full Connect Scan в Wireshark
**Статус:** Выполнено
**Роль:** Аналитик Blue Team (SOC)
**Окружение:** Ubuntu Linux (RAM-Run via Ventoy) + Wireshark

## 1. Сводка инцидента (Summary)
В ходе мониторинга сетевого трафика в дампе `scan_attack.pcap` обнаружена аномальная активность, характерная для проведения разведки (сканирования портов) утилитой Nmap.

## 2. Параметры атакующего
* **IP-адрес источника (Source IP):** `10.168.11.250`
* **Целевые порты (Target Ports):** 80 (HTTP), 443 (HTTPS), 256
* **Тип атаки:** Full Connect Scan (Полное сканирование с установлением сессии)

## 3. Ход анализа и таймлайн пакетов
Для детекта использовался дисплейный фильтр:
`tcp.flags.syn == 1 && tcp.flags.ack == 0`

* **Аномалия:** С хоста `10.168.11.250` зафиксирован массовый штурм портов 80, 443 и 256.
* **Реакция сервера (Порт 80):** Успешное прохождение трехэтапного рукопожатия (TCP 3-Way Handshake).
* **Завершение сессии:** Со стороны атакёра (`10.168.11.250`) зафиксирован пакет с флагами `FIN, ACK` длиной `66 байт`. Это подтверждает, что атакующий программно убедился в доступности веб-службы на порту 80 и закрыл соединение.

## 4. Вердикт и рекомендации
1. Хост `10.168.11.250` официально признан компрометирующим.
2. Веб-сервер (порт 80) открыт наружу и полностью разведан злоумышленником.
3. **Рекомендация:** Настроить правила IPTables/Stateful Firewall для блокировки сканирующего IP и ограничить доступ к порту 256.
